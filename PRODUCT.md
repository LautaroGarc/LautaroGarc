# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- **Recruiters and hiring teams** evaluating Lautaro García as a Software Developer: they skim fast, want to know what he builds and how well, and leave with the CV.
- **Prospective clients** with a concrete problem who want to know whether he can solve it end to end.

## Product Purpose

Personal portfolio of Lautaro García, Software Developer. It presents him professionally, lets the visitor download the CV or navigate the sections, and routes each project to its own destination. Success: a visitor understands within seconds how he works, downloads the CV or opens a project.

## Positioning

He doesn't sell "frontend" or "backend". He solves problems with a repeatable method (understand, define what "done" means, build, verify) so quality is predictable — "calidad determinística". Solutions are genuine to the problem, not generic templates. The portfolio must show the method, not just claim it.

## Operating Context

- Header + home page with professional sections: presentation, method, projects, stack, contact.
- Hero carries two actions: download CV and navigate the site.
- Projects section tells something about each project and links out to its destination.

## Capabilities and Constraints

- Stack already in repo: React Router 8 (SSR), React 19, Tailwind 4, Vite, Docker.
- Projects link externally; no project landings live inside this site.
- More projects are coming: the project list must be data-driven and easy to extend.
- Copy language: Spanish (Argentina).

## Brand Commitments

- Name: Lautaro García. Title: **Software Developer**.
- GitHub: github.com/LautaroGarc.

## Evidence on Hand

- **Nexandría** — library management system built around a network of libraries: a reader can request any book from any branch of the network. Built to solve the real problem rather than ship a generic solution. Landing: https://nexandria.com.ar
- **GoNext** — web backend framework for Go, inspired by NestJS: aims to replicate that software's quality and structure with Go's benefits. Repo: https://github.com/LautaroGarc/GoNext
- Skills (from README badges): JavaScript, TypeScript, Python, HTML, CSS, MySQL, PostgreSQL, Redis, SQLite, React, React Native, Expo, Next, React Router, React Query, React Hook Form, Tailwind, Vite, Express, Zod, NPM, Framer, Illustrator, Photoshop, Kali Linux. Go (via GoNext).
- **Absent, must not be fabricated:** CV PDF (placeholder at `/cv.pdf`), email/LinkedIn (placeholders), metrics, testimonials, employers, users counts for any project.

## Product Principles

1. Show the method, don't claim it: every project is told through the same steps.
2. Problem first, technology second.
3. Every claim on the page is true and checkable.
4. Adding a project is adding data, not redesigning.
